# TellCo Telecom Customer Analytics

## Project Overview

This project analyzes TellCo telecom customer data to understand user engagement, user experience, and customer satisfaction.

## Dashboard

The interactive dashboard is built using Streamlit and Plotly.

## Analysis Tasks

- User Overview Analysis
- User Engagement Analysis
- User Experience Analysis
- User Satisfaction Analysis
- ML Model Tracking using MLflow

## Technologies Used

Python
Pandas
Plotly
Streamlit
Machine Learning
MLflow

## Files

- app.py - Streamlit dashboard application
- user_engagement.csv - User engagement data
- user_experience.csv - User experience data
- final_satisfaction_table.csv - Final satisfaction scores
- requirements.txt - Python dependencies
